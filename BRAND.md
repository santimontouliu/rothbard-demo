# Rothbard palette
Inspected https://rothbardgroup.com on November 8, 2026.
Core colors read from the rendered website: linen #EFEDE6, charcoal #3C3C3B, primary button sienna #9D4325. Accent token: hsl(15 63% 59.5%); warm card token: hsl(40 33% 97%).
The demo uses those core colors and derived warm borders/tints. No external font or image downloads were added. This matches the palette, not a complete official brand system. The monogram is the demo mark, not the official Rothbard logo.
